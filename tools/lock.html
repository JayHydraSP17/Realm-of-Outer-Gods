Seal a page

Turns a sheet into a passphrase-locked page that's safe to put in the public repo. Everything happens in this browser; nothing is uploaded.

Use the same passphrase as the other DM sheets so "Remember on this device" covers them all. Save the result into mythic-covenant/dm/ with a neutral name (s3.html, s4.html…), and make sure the sheet loads ../firebase-config.js.
